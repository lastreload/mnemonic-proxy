# Batch recall fixture provenance

`recall_batch_0726.json` contains the verbatim archive contents and original record metadata for the
wrong first pick, the correct round-18 record, and the correct round-24 record from the PR #24
AgentLongBench pilot (`64k/28_i18_j24_a_0726`, B). It was exported over read-only SSH with
`sqlite3.connect('file:<path>?mode=ro', uri=True)` from:

`/mnt/mneme-nvme/proxy-ideas/alb-bench-v2/runs/paging-ab-t_7b1cb844/gpu/pilot/B/D/kf-c/64k/28_i18_j24_a_0726/proxy/archive.sqlite`

The tests use `ctxproxy.fake_engine.FakeEngine`, never an inference engine. Numeric JSON has high
token density; the CI fixture uses an explicit deterministic chars-per-token counter, not a claim
of reproducing the original model tokenizer or its answers. The strict fake engine checks every
request, including the answer budget. The frozen-budget offline replay uses the original tokenizer
separately (see the issue #25 result report).

`recall_single_0313.json` contains 18 golden tool outputs generated by `Proxy` from main commit
`a4ba0e8` (0.3.13), using the same fake-engine harness and original fixture. They cover full outputs,
continuation offsets, late queries, `mode=output`, no-match, short records and constrained windows.
They are compared as UTF-8 bytes, including headers, cursor values and closing notes.
